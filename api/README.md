# Church Register — API (Laravel 13)

API et service du SPA du registre des visiteurs de l'Église La Maison de la Destinée.

- Installation, développement et scripts : voir le [README principal](../README.md).
- Contrat d'API (source de vérité) : [docs/api-contract.md](../docs/api-contract.md).
- Déploiement Hostinger : [docs/deploiement.md](../docs/deploiement.md).

Commandes utiles :

```bash
composer test      # Pest (MariaDB, base church_test)
composer analyse   # Larastan
composer lint      # Pint --test
php artisan admin:create   # premier super administrateur (interactif)
```
